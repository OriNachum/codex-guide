# Privacy Policy

**Codex Guide**
**Last updated:** March 7, 2026

## Overview

Codex Guide is an open-source, content-first repository that provides local skills and reference documentation for Codex. This privacy policy explains what the contents of this repository do and do not collect.

This policy covers the files in this repository. It does not cover the Codex product, the model provider, GitHub, or any tools you separately configure or invoke while using Codex.

## Data Collection

**The contents of this repository do not themselves collect, store, transmit, or process user data.**

Specifically, the files in this repository:

- do **not** collect personal information
- do **not** add analytics or telemetry
- do **not** contain cookies or browser storage
- do **not** include executable scripts, binaries, hooks, or MCP servers
- do **not** integrate with external services on their own

## What the Repository Contains

This repository consists of static project guidance files, including:

- `README.md` and `AGENTS.md`
- Markdown skill definitions in `skills/`
- reference documentation in `skills/codex-guide-ask/references/`
- YAML agent metadata in `skills/*/agents/openai.yaml`

These files are read as local project content. They do not introduce a separate background service or data pipeline.

## Third-Party Services

This repository does not bundle third-party services or external dependencies.

However, when you use Codex, the underlying Codex product and any tools you enable or approve may have their own data handling behavior. Review those product and service policies separately.

## Open Source

## Changes to This Policy

If the repository contents change in a way that affects data handling, this privacy policy will be updated accordingly. Changes will be reflected in the repository and the "Last updated" date above.
