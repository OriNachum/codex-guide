# Getting Started

Start here if you are new to Codex in a repository.

## Core pages

- [Getting started reference](../skills/codex-guide-ask/references/getting-started.md)
- `codex-guide-onboarding` for an interactive first-run walkthrough inside Codex

## What to learn first

- Make the repo legible with `AGENTS.md`
- Pick a small first task with clear verification
- Ask Codex to inspect before it implements when the task is not trivial
- Review diffs and command results instead of trusting summaries

## Next step

After this section, move to [Working with Codex](working-with-codex.md) and try
the `$codex-guide-onboarding` skill locally for an interactive walkthrough.
