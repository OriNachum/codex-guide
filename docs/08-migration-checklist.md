# Claude-to-Codex Migration Checklist

Use this checklist when moving team workflows from Claude-style habits to Codex-native execution.

## Prompt quality

- [ ] Requests specify target files/folders.
- [ ] Constraints are explicit (frameworks, API stability, no broad rewrites).
- [ ] Validation commands are listed.
- [ ] Deliverables include docs/tests when relevant.

## Repository policy

- [ ] `AGENTS.md` exists and is current.
- [ ] Nested instruction scopes are intentional.
- [ ] Required checks are codified.
- [ ] PR format expectations are codified.

## Delivery quality

- [ ] Changes are minimal and scoped.
- [ ] Commands were actually run and reported.
- [ ] Blockers are explicit with fallback reasoning.
- [ ] Commit and PR artifacts are complete.
