# Exercises

These are real-repo missions. The point is not to simulate work; it is to learn
Codex by improving `codex-guide` itself.

## Before you start

- Read [Getting Started](getting-started.md)
- Keep your tasks small and reviewable
- Prefer one mission per branch or PR
- Use `$codex-guide-introspect` after a mission to see what the repo still needs

## Mission ladder

1. [Tighten `AGENTS.md`](exercises/mission-1-tighten-agents.md)
2. [Add the site skeleton](exercises/mission-2-site-skeleton.md)
3. [Publish the custom domain](exercises/mission-3-publish-domain.md)
4. [Improve GitHub issue hygiene](exercises/mission-4-issue-hygiene.md)
5. [Build the introspection skill](exercises/mission-5-introspection-skill.md)
6. [Add docs freshness audits](exercises/mission-6-docs-freshness.md)
