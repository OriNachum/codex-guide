- `$codex-guide-onboarding` for an interactive first-run walkthrough
- `$codex-guide-ask` for grounded answers from the local guide corpus
- `$codex-guide-introspect` for repo setup audits and next-step improvement plans

## Learning approach

This guide treats Codex as a collaborator you supervise, not a black box you
trust blindly.

The default loop is:

1. inspect the repo
2. make the plan visible
3. implement in small steps
4. verify with commands
5. review the diff

The exercises section applies that loop to `codex-guide` itself so you can learn
on a real codebase with visible outcomes.
